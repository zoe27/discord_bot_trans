# 🧩 实时屏幕翻译工具 - Discord / Slack / Telegram 聊天助手

这是一个桌面小工具，支持在 Discord、Slack、Telegram 等平台上：
- 实时翻译聊天区域内容（无需复制粘贴）
- 输入熟悉语言翻译为目标语言，用于跨语言对话

## ✨ 核心功能
- 🖱 屏幕任意区域选中，OCR + 实时翻译
- 🗣 输入框翻译：输入中文转英文发送
- 💬 支持多平台（Discord、Slack、Telegram）
- ⚡ 自动触发，无需手动复制或点击翻译
