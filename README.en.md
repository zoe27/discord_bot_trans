# 🧩 Real-Time Screen Translator for Discord / Slack / Telegram

A lightweight desktop tool that helps you **chat across languages** by translating **any text on screen in real time** — perfect for use in **Discord**, **Slack**, **Telegram**, or even in **games**, **PDFs**, and **videos**.

---

## 🔧 What It Does

- 🖱 **Select any area on your screen** — chat windows, images, videos, PDFs, etc.
- 🔍 **Instant OCR** — recognizes text inside the selected area.
- 🌐 **Real-time translation** — immediately shows the translation without any copy-pasting.
- 💬 **Bidirectional support** — input your message and translate it into your target language before sending.
- ⚡️ Works like magic — no switching apps, no browser tabs, just seamless overlay translation.

---

## 🎯 Use Cases

- 💬 Chatting with foreign teammates in Discord / Slack
- 🕹 Playing Japanese or Chinese games with on-screen translations
- 📚 Reading scanned papers or image-only PDFs
- 🗨 Talking with overseas friends even if you don't speak their language
